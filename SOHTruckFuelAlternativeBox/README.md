# SOHTruckFuelAlternativeBox

An extension of [SOHLogisticsBox](../SOHLogisticsBox/README.md) for comparing diesel, battery-electric and hydrogen
trucks. It adds swappable energy models, energy- and legal-time-aware stop planning, and database metrics.

Shared road-network preprocessing, routing foundations and logistics concepts are documented in
[SOHLogisticsBox](../SOHLogisticsBox/README.md); only the extension-specific details are covered here.
